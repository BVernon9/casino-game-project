# Casino Game Project
Source code for a completed Python-based casino game with blackjack, roulette, slot machines and horse racing (13/12/2024). Seperate original standalone inital games created are 'blackjack.py', 'roulette.py' and  'horsey race race.py' then horse racing was updated to be visual rather than a background math simulation and is 'visual horses race.py'. Then final game was fully integrated together with a working menu and transferrable currency system and is the 'full_game.py' file.

## Personal Contribution

As this was part of a group project I did not design the full code, I personally created the horse racing game in full and integrated all the other games together into the full game file.

## How to run

- Clone this repo
- Run `python full_game.py`
